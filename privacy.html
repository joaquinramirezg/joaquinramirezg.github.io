Privacy

This is my personal portfolio. It has no accounts, no forms, no newsletter, and nothing to buy, so there is very little to say here. Everything below is the whole story.

Cookies

This site sets no cookies and uses no local storage. Nothing is stored on your device, so there is no consent banner to click.

Analytics

I use Umami, a privacy-friendly analytics tool, to see whether the page is being read and which parts hold attention. It is cookieless and collects no personal data. What I can see is aggregate and anonymous:

  • Page views, and which sections were on screen long enough to be read
  • Where visits came from, such as a search engine, LinkedIn, or a direct link
  • Country and region, derived from your IP address and then discarded, never stored
  • Browser, operating system, and screen size
  • Clicks on my resume, GitHub, LinkedIn, and email links

I cannot see who you are. There are no individual profiles, no cross-site tracking, no session recordings, no advertising, and nothing is sold or shared. If your browser sends a Do Not Track signal, this site records nothing at all.

Files served from this site

My resume is a static PDF hosted here. Opening it tells me a resume link was clicked, nothing more.

Third parties

Fonts are served from this site, not from a font provider. The site itself is hosted on GitHub Pages, and the analytics described above run on Umami Cloud. Both see the standard request information any web server receives.
